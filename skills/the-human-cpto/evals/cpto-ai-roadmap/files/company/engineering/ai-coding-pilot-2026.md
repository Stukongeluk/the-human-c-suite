# AI coding assistant pilot - May to September 2026 (summary by the developer experience group)

Teams with the tool: Routing (22) and Fleet app (24). Comparison team without the tool: Integrations (20). Same quarter-on-quarter comparison, Q1 2026 vs Q3 2026.

| Metric | Routing | Fleet app | Integrations (comparison) |
|---|---|---|---|
| Self-reported "I am faster" (survey) | 71% | 64% | n/a |
| Self-reported time saved | 35% | 30% | n/a |
| Median cycle time change | -6% | -3% | -1% |
| Pull requests merged | +38% | +31% | +2% |
| Median pull request size | +70% | +58% | +4% |
| Median review wait time | +55% | +49% | +3% |
| Change fail rate (percentage points) | +2 | +1 | 0 |
| Escaped defects | +12% | +9% | -2% |
| Static analysis security findings per 1k changed lines | +30% | +22% | +1% |

Vendor materials claim developers complete tasks "55% faster". Seats: 160 bought in April 2026 for all engineers; 61 weekly active users in October. No change was made to review practices during the pilot. Several seniors said review load "doubled".
