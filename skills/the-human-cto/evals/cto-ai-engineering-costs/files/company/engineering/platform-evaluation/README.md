# Deployment platform consolidation - evaluation pack

Brightlane runs three deployment platforms. The MT asked for one standard platform by mid-2027.

- **Harbor**: Kubernetes on our cloud account, run by the Platform team since 2021. Used by Routing, Integrations and Data.
- **Beacon**: in-house PaaS built in 2023 by the Platform team under its current lead. Used by the Platform team's own services and the Mobile backend. Keeping Beacon running takes about 6 of the 14 Platform engineers.
- **Corral**: a managed vendor PaaS, used by Fleet app since 2024.

The evaluation was run by the architecture group, chaired by the Platform lead. Scores were agreed in a workshop on 28 October 2026. See scores.csv, change-log.md and production_metrics_q3_2026.csv.
